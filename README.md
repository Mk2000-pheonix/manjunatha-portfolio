# Manjunatha M K — Portfolio V4

A dark, modern, responsive portfolio for showcasing Data Engineering, Azure and Enterprise IT / EUC experience.

## What's new in V4
- Clickable Data Engineering and Enterprise IT skill cards.
- Clickable Skills Overview cards with editable detail modals.
- Money Detective project opens an editable project-detail modal and remains clearly marked **In Development**.
- Placeholder LinkedIn, GitHub and Resume buttons now explain where to add real URLs/files.
- Smooth internal navigation and keyboard-accessible cards.
- No framework or build step — edit `index.html`, `style.css` and `script.js` directly.

## Add your real links
In `index.html`, replace buttons with `data-placeholder-link` and `href="#"` with your actual URL. For example:

```html
<a class="btn primary" href="https://www.linkedin.com/in/YOUR-ID/">LinkedIn</a>
```

For the resume, place a PDF in `assets/` and point the button to it:

```html
<a class="btn" href="assets/Manjunatha-M-K-Resume.pdf" download>↓ Download Resume</a>
```

## Money Detective
Keep the project status as **In Development** until each part is actually completed. Add GitHub, architecture images, screenshots and dashboard links as they become available.
